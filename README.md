# Projekt2026

Vizualizátor generování a řešení bludišť

Popis projektu
Projekt je desktopová aplikace vytvořená v jazyce Python s využitím grafické knihovny Pygame. Cílem je názorně a v reálném čase vizualizovat fungování základních grafových a prohledávacích algoritmů na 2D mřížce.Generování bludiště: Aplikace vytváří unikátní, náhodně vygenerované bludiště.
Hledání nejkratší cesty: Po určení startu a cíle uživatel spustí řešící algoritmus. Program animuje, jak algoritmus prohledává buňky, a po dosažení cíle zvýrazní nejkratší cestu.
