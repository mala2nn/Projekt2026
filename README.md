# Projekt2026

Vizualizátor generování a řešení bludišť

Popis projektu
Projekt je desktopová aplikace vytvořená v jazyce Python s využitím grafické knihovny Pygame. Cílem je názorně a v reálném čase vizualizovat fungování základních grafových a prohledávacích algoritmů na 2D mřížce.Generování bludiště: Aplikace vytváří unikátní, náhodně vygenerované bludiště.
Hledání nejkratší cesty: Po určení startu a cíle uživatel spustí řešící algoritmus. Program animuje, jak algoritmus prohledává buňky, a po dosažení cíle zvýrazní nejkratší cestu.

Plán práce (Roadmap)

1. Příprava a základy 

[x] Výběr tématu, schválení a založení GitHub repozitáře.
[ ] Vytvoření základního okna v Pygame a vykreslení 2D mřížky.

2. Tvorba bludiště a ovládání 

[ ] Zprovoznění interakce (kreslení zdí...).
[ ] Implementace a animace algoritmu pro náhodné generování bludiště.

3. Hledání cesty 

[ ] Naprogramování algoritmů pro nalezení nejkratší cesty (např. BFS, A*).
[ ] Animace průchodu bludištěm a finální zvýraznění nalezené trasy.

4. Dokončení 

[ ] Optimalizace plynulosti, oprava chyb a začištění kódu.
